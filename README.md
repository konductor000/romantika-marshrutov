# Романтика маршрутов

Инструменты телеграм-канала [@romantika_marshrutov](https://t.me/romantika_marshrutov) — клуба, где раз в три месяца рандомайзер выбирает страну и мы разбираем её по неделям.

## Что здесь

| Что | Зачем |
|---|---|
| [`бот/`](бот/) | Бот клуба [@romantika_marshrutov_bot](https://t.me/romantika_marshrutov_bot): задания недели, паспорт сезона со штампами, словарик, журнал к финалу |
| `опубликовать_пост_с_кнопкой.sh` | Разовая публикация поста с кнопкой-ссылкой в канал |

Запуск и команды бота — в [`бот/КАК ЗАПУСТИТЬ.md`](бот/КАК%20ЗАПУСТИТЬ.md).

## Как устроен сезон

Двенадцать недель. Каждый понедельник выходит задание: **минимум** на пять минут и **максимум** на вечер, оба необязательные. В воскресенье — итоги с именами тех, кто сделал.

За выполненную неделю человек получает штамп в паспорт сезона. Пропущенная неделя тратит **заморозку** — их две базовых плюс до трёх заработанных, и цепочка от пропуска не рвётся. К финалу каждый участник получает свой журнал: его недели его же словами, фотографии, ачивки, словарь.

Первый сезон — Мексика, 18.08 — 18.11.2026.

`токен.txt`, `админ.txt` и `данные.sqlite` — доступы и данные участников. Они только на рабочей машине, в git не попадают.
