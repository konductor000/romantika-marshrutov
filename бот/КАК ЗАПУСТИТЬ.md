# Бот «Романтика маршрутов»

Работает на том Python, который уже есть в маке. Ничего устанавливать не нужно.

## Первый запуск — три шага

**1. Положить токен.**
BotFather → `/token` → выбрать `@romantika_marshrutov_bot` → скопировать строку.
Создать рядом с этим файлом файл `токен.txt` и вставить туда только сам токен, без кавычек и пробелов.

**2. Запустить.**
Открыть Терминал и выполнить:

```
cd "/Users/milanabelonosova/Посты в тг. Романтика маршрутов/бот"
python3 бот.py
```

Должно написать: `Бот @romantika_marshrutov_bot запущен`.
Пока окно Терминала открыто — бот живой. Закрыла окно или выключила мак — бот замолчал.

**3. Стать админом.**
Написать боту в Телеграме `/whoami`, он вернёт число. Создать файл `админ.txt`, вставить туда это число. Перезапустить бота (Ctrl+C, потом снова `python3 бот.py`).

Без этого шага бот работает, но админские команды недоступны.

## Что видят участники

Шесть кнопок в три ряда:

| | |
|---|---|
| **📋 Задание** | задание недели с кнопками «Берусь · Попробую · В этот раз мимо» |
| **🌤 Сегодня** | день цолькина и слово дня, меняется каждые сутки |
| **📘 Паспорт** | штампы за сезон, статус, сколько заморозок осталось |
| **📖 Словарь** | слова сезона, которые уже вышли, плюс добавленные людьми |
| **💡 Что узнали** | факты сезона, по одному на пост |
| **⋯ Ещё** | журнал, «Написать Миле», помощь |

Под «Ещё» ушло то, что открывают раз в месяц. Раньше рядов было пять и клавиатура закрывала пол-экрана.

**Журнал специально убран с клавиатуры**, но никуда не делся: он в «Ещё» и в паспорте под кнопкой «Что будет в конце сезона». Сбор данных для него идёт сам — отчёты, фото, слова, ачивки и факты пишутся в базу при каждом действии, независимо от того, открывает кто-нибудь журнал или нет.

Старые подписи кнопок бот тоже понимает: у людей клавиатура закэширована телеграмом и перерисуется только когда они напишут `/start`.

Чтобы сдать задание, человек просто присылает боту текст или фото. Ничего нажимать не надо.

- прислал **текст** → засчитывается **минимум**, обычный штамп
- прислал **фото или видео** → засчитывается **максимум**, штамп со звёздочкой

Под ответом есть кнопка «Это был максимум/минимум» — если бот угадал неправильно, человек поправит сам.

## «Сегодня» — ежедневная штука

Знак цолькина считается по формуле, вручную ничего вводить не надо. Корреляция **GMT-584283** — та же, что в календаре-миниприложении, так что бот и приложение показывают один и тот же день.

Толкования традиционные (Эб — дорога, Ахау — солнце и завершение), а не выдуманное предсказание. Внизу приписка, что это счёт, который в Гватемале ведут до сих пор.

**Это свойство страны, а не бота.** В `сезон.json` есть блок `daily`:

```
"daily": { "kind": "tzolkin", "title": "…", "note": "…" }
```

У новой страны своё: у Японии рокуё — шесть дней удачи, их до сих пор печатают в календарях. У Китая шестидесятидневный цикл. А у Португалии или Исландии аналога нет — тогда блок `daily` просто убирается, кнопка остаётся, и в ней будет только слово дня. Ничего переписывать не придётся.

Полезный факт на финал: **18 ноября 2026 — 1 Ахау.** Ахау — знак солнца и завершения, единица начинает новый тринадцатидневный цикл. Ровно в день, когда сезон кончается и разыгрывается следующая страна.

## Команды для тебя

- `/results` — сводка за текущую неделю: кто взялся, кто сдал, кто взялся и молчит. Внизу — готовый кусок текста для воскресного поста с именами
- `/results 2` — то же самое по любой неделе по номеру
- `/remind` — разослать напоминание тем, кто взялся, но ещё не прислал. Уходит только им, не всем подряд
- `/core` — **ядро сезона**: кто сдаёт задания две недели подряд. Главная цифра: по ней решается, есть ли что продавать. Ориентир к 18.09 — пятеро, порог для платного клуба — пятнадцать
- `/who` — все, кто вообще писал боту
- `/reminders` — включить или выключить автонапоминания (по умолчанию включены)
- `/badges` — список ачивок с кодами
- `/ачивка` — выдать ачивку, три способа:
  - ответом на присланный отчёт: `/ачивка повар`
  - по нику или имени: `/ачивка @ksu повар` · `/ачивка Кирилл проводник`
  - своими словами: `/ачивка @ksu 🌶 Первопроходец`

## Ответить человеку на отчёт

Когда кто-то присылает задание, тебе приходит уведомление. **Ответь на него реплаем** — бот передаст твой текст автору от твоего имени. Он увидит: «💬 Мила ответила на твой отчёт: …».

Это самое дешёвое, что вообще работает: человек прислал фото и через минуту получил живой ответ, а не тишину.

## Автонапоминания

Уходят **два раза за неделю** и только тем, кто нажал «Берусь» или «Попробую» и ещё не прислал:

- **четверг, 19:00** — «впереди выходные, как раз время»
- **воскресенье, 12:00** — «сегодня до 18:00»

Нажавшим «В этот раз мимо» не приходит ничего. Тебе после каждой рассылки прилетает отчёт, сколько ушло.

Два, а не три — задание необязательное, и лишнее напоминание про необязательное превращает клуб в работу. Выключить и включить обратно: `/reminders`.

Работают, только пока бот запущен. Если мак спал в четверг вечером — напоминание уйдёт при следующем запуске в тот же день, а если день прошёл, то пропустится.

## Ачивки

Выдаются **руками, за поступок**, а не начисляются машиной. В этом весь смысл: человека заметили лично.

Каталог лежит в `сезон.json` в разделе `achievements` — можно менять и дописывать под страну. Ачивка появляется у человека в паспорте и попадёт в итоговый журнал сезона.

Каждый отчёт и каждое «берусь» бот пересылает тебе в личку сразу, так что можно ничего не запрашивать.

## Зачем это всё

Опрос в канале анонимный — 5 человек нажали «приготовлю», и ты не знаешь кто. Бот ту же кнопку показывает с именем. Дальше в четверг пишешь этим пятерым, а не всем 47.

## Как поменять задания

Открыть `сезон.json` в любом текстовом редакторе. Там все 12 недель Мексики: название, даты, слово недели, минимум, максимум. Меняешь текст — перезапускаешь бота.

Для новой страны: скопировать файл, переписать содержимое, даты поставить новые.

### Правило: начавшаяся неделя не меняется

Будущие недели можно переставлять и переписывать сколько угодно — там ещё нет ни штампов, ни отчётов, ломать нечего.

А неделю, которая уже началась, не трогаем. Люди её прожили: увидели задание, что-то сделали, получили штамп. Задним числом переименовать то, что человек сделал, — это как переписать чужую запись в дневнике.

**Бот на этот случай подстрахован.** В момент выдачи штампа он запоминает название недели прямо в базу. Если потом переставить недели в `сезон.json`, паспорт всё равно покажет то, что человек делал на самом деле, а не то, как теперь называется этот номер.

То есть даже если правило нарушить — данные не испортятся. Но лучше не нарушать: у людей на экране написано одно, а в канале станет другое.

## Файлы

| Файл | Что это |
|---|---|
| `бот.py` | сам бот |
| `сезон.json` | задания по неделям, редактируется руками |
| `токен.txt` | токен от BotFather. **Никому не показывать** |
| `админ.txt` | твой telegram id |
| `данные.sqlite` | участники, отчёты, штампы. Появится сам при первом запуске |

## Если что-то пошло не так

**«Нет токена»** — файл `токен.txt` не создан или пустой.

**«Токен не подошёл»** — в файле лишние символы. Должна быть одна строка вида `1234567890:AAF...`.

**Бот не отвечает** — проверь, что окно Терминала открыто и в нём написано «запущен». Ошибки бот печатает туда же, но не падает: сеть моргнула — продолжит сам.

**Остановить** — Ctrl+C в Терминале.

## Журнал сезона в PDF

Отдельный скрипт `журнал.py`. Собирает страницу из базы и печатает её через Chrome — ставить ничего не надо.

```
python3 журнал.py --образец      посмотреть на выдуманных данных
python3 журнал.py 355363829      journal одного человека
python3 журнал.py --все          всем, у кого есть хоть один штамп
```

Готовое кладётся в папку `журналы`. Фотографии скачиваются из Телеграма по `file_id` автоматически.

# Переезд на сервер

Что нужно знать тому, кто разворачивает.

**Зависимостей нет.** Python 3.9 или новее, стандартная библиотека. Ни pip, ни venv.

```
git clone https://github.com/milanosova/romantika-marshrutov.git
cd romantika-marshrutov/бот
python3 бот.py
```

## Три вещи, которых нет в репозитории

Они намеренно не в git — их нужно создать на сервере руками:

| Файл | Что положить |
|---|---|
| `токен.txt` | Токен от BotFather, одной строкой |
| `админ.txt` | Telegram id владельца, одним числом |
| `данные.sqlite` | **Скопировать с рабочей машины**, а не создавать заново |

<b>Про базу — важно.</b> Если не перенести `данные.sqlite`, потеряются все участники, отчёты, штампы, слова, ачивки и факты. Бот заведёт пустую и не пожалуется. Копировать при остановленном боте.

## Часовой пояс

Автонапоминания привязаны к **местному времени сервера**: четверг 19:00 и воскресенье 12:00. Если сервер в UTC, они уйдут на три часа раньше московского.

```
sudo timedatectl set-timezone Europe/Moscow
```

## Чтобы поднимался сам

Бот держит длинный опрос и не завершается. Сеть моргнула — переживёт сам, но после перезагрузки сервера его надо поднять. Проще всего systemd:

```
[Unit]
Description=Романтика маршрутов
After=network-online.target

[Service]
WorkingDirectory=/путь/до/бот
ExecStart=/usr/bin/python3 бот.py
Restart=always
RestartSec=10
User=имя

[Install]
WantedBy=multi-user.target
```

## Только один экземпляр

Телеграм отдаёт очередь обновлений **одному опрашивающему**. Если бот останется работать и на маке, и на сервере — оба начнут получать ошибку 409 и терять сообщения. **Перед запуском на сервере остановить локальный.**

## Обновление кода

```
git pull
sudo systemctl restart romantika
```

`токен.txt`, `админ.txt` и база при этом не трогаются — они не в репозитории.
